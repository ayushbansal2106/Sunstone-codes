# Grocery Store Billing System (Java OOP - Terminal Based)

## Description
A terminal-based billing system for a grocery store using Java Object-Oriented Programming. It allows you to add/remove products, generate bills with 18% flat tax, and print receipts with timestamp and a 5-digit unique bill ID.

## Features
- Add / Remove products from inventory
- View product list
- Generate bill with 18% tax
- Print formatted receipt with date and bill ID
- INR currency format

## Concepts Used
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction

## How to Compile and Run

1. Navigate to the `src` folder in terminal:
```
cd src
```

2. Compile the code:
```
javac *.java
```

3. Run the program:
```
java Main
```
