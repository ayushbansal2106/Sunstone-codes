# Bank Management System (Java - OOP)

This is a simple terminal-based bank management system built using Java and Object-Oriented Programming principles.

## Features
- Admin login (username: admin, password: admin123)
- Create Savings or Current accounts
- Deposit and withdraw money
- View account balance and transaction history
- Interest calculation for Savings accounts (3%)
- Delete accounts (Admin only)

## Concepts Used
- Inheritance and Polymorphism
- Abstract classes and method overriding
- Exception handling
- Menu-driven user interface

## How to Run
1. Compile all `.java` files in the `src` folder.
2. Run `Main.java`

## Note
This project uses in-memory storage. All data is lost after the program exits.
