# Bank Management System (Java - OOP, No Collections)

This simple terminal-based bank system in Java demonstrates OOP concepts without using collections.

## Features
- Admin Login (admin/admin123)
- Create Account (Savings/Current)
- Deposit / Withdraw
- View Balance
- Apply Interest (only to Savings)
- Delete Account

## How to Run
1. Compile all `.java` files inside the `src` folder.
2. Run `Main.java`.

## OOP Concepts Used
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation
